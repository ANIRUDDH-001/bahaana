# Bahaana API

The model server behind [Bahaana](https://bahaana.onrender.com). It answers `POST /v1/verdict` with an active-day
likelihood and excuse verdicts from TabPFN v2, and `GET /healthz` with a liveness check.

It is stateless: rows arrive without dates, are used for one prediction, and are not stored or logged.

Built with TabPFN v2 by Prior Labs (`Prior-Labs/TabPFN-v2-clf`), downloaded at build time under its own license.
Weather: Open-Meteo.

This folder is generated by `scripts/make_space.py` in the Bahaana repository. Edit there, not here.
